## 二、讲解版是怎么做的

1. **配音**：`edge-tts` 调用微软神经网络语音 `zh-CN-YunxiNeural`（云希，男声），语速 +4%，逐段生成 mp3；
2. **计时**：读出每段音频时长，把它作为该步骤在视频里的停留时长；
3. **录制**：Playwright 驱动 Chromium 真实操作，每一步记录起始时间戳到 `timeline.json`；
4. **混音**：用 ffmpeg 的 `adelay` 把各段音频推到对应时间点，`amix` 合并成一条音轨；
5. **压制**：`libx264 -crf 22` + `aac 128k`，`+faststart` 让网页播放不用等整段下载。

工具都在 [录制工具/](录制工具/)：

| 文件 | 作用 |
| --- | --- |
| `narration.py` | 配音文案 + edge-tts 合成 + 生成 durations.json |
| `record-narrated.cjs` | 按配音时长自动控制节奏录制，输出 webm + timeline.json |
| `build-narrated.cjs` | 混音 + 压制 mp4 |
| `../record-demo.cjs` | 无配音的快速版录制脚本 |

## 三、重新录制

```bash
# 项目根目录
npm init -y
npm i -D playwright @ffmpeg-installer/ffmpeg
npx playwright install chromium

# 1. 生成配音（需要 pip install edge-tts）
python docs/录制工具/narration.py "$(node -e "console.log(require('@ffmpeg-installer/ffmpeg').path)")"

# 2. 录制（脚本里的路径按需调整）
node docs/录制工具/record-narrated.cjs

# 3. 混音压制
node docs/录制工具/build-narrated.cjs
```

改文案就改 `narration.py` 里的 `SEGMENTS`；改操作就改 `record-narrated.cjs` 里的 `step(...)`。

> 录制前确保 `http://127.0.0.1:8801` 服务在跑、数据是演示数据（`cd server && npm run db:seed` 可重置）。

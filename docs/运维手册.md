## 四、备份

### 自动

```
每天 03:30（含 5 分钟随机延迟）
→ systemd: medai-backup.timer → medai-backup.service → deploy/backup.sh
```

产出：

```
/opt/backups/
├── medai-2026-11-04_034056.sql.gz     # 数据库（含表结构与数据）
├── env-2026-11-04_034056.tar.gz       # server/.env（数据库密码、JWT、DeepSeek Key）
└── 保留 14 天，自动清理
```

### 手动执行

```bash
bash /opt/medai/deploy/backup.sh
ls -lh /opt/backups/
```

### 验证备份可用（已实测通过）

```bash
mysql -e "DROP DATABASE IF EXISTS medai_restore_test; CREATE DATABASE medai_restore_test;"
gunzip -c /opt/backups/medai-最新.sql.gz | mysql medai_restore_test
mysql -N -e "SELECT COUNT(*) FROM information_schema.tables WHERE table_schema='medai_restore_test';"
mysql -e "DROP DATABASE medai_restore_test;"
```

实测结果：**15 张表 / 36 份病历 / 6 篇知识文档，完整恢复**。

### 恢复（会覆盖现有数据）

```bash
bash /opt/medai/deploy/restore.sh /opt/backups/medai-2026-11-04_034056.sql.gz
# 输入 yes 确认；脚本会先给当前库做一份快照，再导入
```

### 建议补充（控制台操作）

阿里云控制台 → 实例 → 快照 → **开启自动快照策略（每天 1 次，保留 7 天）**。
数据库备份防误删，快照防整机故障，两者互补。

## 六、安全策略一览

| 层面 | 措施 |
| --- | --- |
| 网络 | ufw 只放行 22/80/443；8801、3306 仅监听 127.0.0.1 |
| SSH | 仅密钥登录、失败 3 次封禁、MaxAuthTries 3 |
| 系统 | `unattended-upgrades` 每日自动打安全补丁 |
| 应用 | JWT + token_version、角色权限、SQL 参数化、审计哈希链 |
| 登录 | 同 IP 15 分钟最多 10 次（超限 429）；连续 5 次失败锁定 15 分钟 |
| AI 责任 | AI 只作初筛，质控医师复核/改判后才形成最终分 |
| 传输 | HTTPS（Cloudflare 隧道，证书自动管理） |
| 数据 | 每日备份 + 完整性校验 + 恢复演练 |

### 6.1 审计链与账号锁定运维

- **校验审计链**：登录后打开「操作日志」→「校验完整性」，或 `GET /api/logs/verify`（需 quality/admin）；
- **重建审计链**：清洗历史日志或迁移数据后执行
  ```bash
  cd /opt/medai/server && npm run audit:rebuild
  ```
  重建会按 id 升序重算 `prev_hash/hash` 并同步 `audit_chain` 链头；
- **账号锁定**：管理员在「用户管理」点「解锁」，或 `PUT /api/users/:id {"unlock":true}`；
- **强制下线**：管理员点「强制下线」，旧 JWT 因 `token_version` 变化立即失效；
- **备份范围**：`audit_logs`、`audit_chain` 必须纳入每日备份；如数据库被高权限直接改库，哈希链只能发现而无法阻止，生产建议同时开启 MySQL 审计日志与异地日志留存。

## 七、应急处理

### 1. 私钥丢失，进不去服务器

阿里云控制台 → 实例 → **远程连接（VNC）** → 用 root 密码登录 → 重新添加公钥：

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
echo "ssh-ed25519 AAAA... new-key" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### 2. 自己的 IP 被 fail2ban 封了

```bash
fail2ban-client set sshd unbanip <你的IP>
```

### 3. 网站打不开

```bash
curl -s http://127.0.0.1:8801/api/health    # 应用活着吗
systemctl restart medai                      # 重启应用
nginx -t && systemctl reload nginx           # Nginx 配置
grep -o "https://.*trycloudflare.com" /var/log/cloudflared.log | tail -1  # 隧道地址是否变了
```

### 4. HTTPS 地址变了

`trycloudflare` 是临时隧道，**服务重启后 URL 会变**：

```bash
grep -o "https://.*trycloudflare.com" /var/log/cloudflared.log | tail -1
```

稳定地址需要 Cloudflare 命名隧道（需注册免费账号）。

### 5. 磁盘满了

```bash
df -h /
du -sh /var/log/* | sort -h | tail -5
journalctl --vacuum-time=7d
ls -lh /opt/backups/   # 备份占多少
```

# 智医质控 MedAI · 云服务器部署指南

## 一、买什么样的服务器

| 项 | 建议 | 说明 |
| --- | --- | --- |
| 配置 | 2 核 2G / 40G 系统盘 | 演示和小规模够用；MySQL 与 Node 同机 |
| 系统 | Ubuntu 22.04 LTS 或 24.04 LTS | 脚本按 Debian 系写的 |
| 带宽 | 1–3 Mbps 即可 | 页面不大，瓶颈在首屏 JS（1.2MB，已 gzip） |
| 安全组 | 放行 22、80、443 | 8801 不要对外开，只给 Nginx 用 |

> 腾讯云 / 阿里云 / 华为云都一样。购买时选择 **Ubuntu 22.04**，记住 root 密码。

## 二、三步上线

### 第 1 步：本地打包并上传

在 Windows 上打开 PowerShell（项目根目录 `F:\deepseek文件`）：

```powershell
# 打包，排除依赖和构建产物（约 1MB）
tar --exclude=node_modules --exclude=dist --exclude=.tmp -czf medai.tar.gz medai

# 上传到服务器（把 IP 换成你的）
scp medai.tar.gz root@你的服务器IP:/tmp/
```

如果 scp 不可用，用 WinSCP / FinalShell / MobaXterm 拖上去一样。

### 第 2 步：服务器上解压并执行脚本

SSH 登录服务器：

```bash
ssh root@你的服务器IP

mkdir -p /opt && cd /opt
tar -xzf /tmp/medai.tar.gz -C /opt
cd /opt/medai

# 执行部署（约 3–5 分钟）
bash deploy/deploy.sh
```

脚本会自动完成：装 Node 20 + MySQL 8 + Nginx → 建库建用户 → 写 `.env`（随机生成数据库密码和 JWT 密钥）→ 导表灌数据 → 构建前端 → 注册 systemd → 配 Nginx → 开防火墙。

**结束时控制台会打印数据库密码，记得复制保存。**

### 第 3 步：浏览器访问

```
http://你的服务器IP
```

账号 `admin / admin123`（上线后请立刻改密码）。

## 三、绑定域名 + HTTPS（建议）

### 1. 域名解析

在域名服务商添加 A 记录：`medai.你的域名.com` → 服务器公网 IP。
⚠️ 国内服务器绑域名需要 **ICP 备案**，没备案会被拦截；不想备案就用 IP 直接访问。

### 2. 改 Nginx 的 server_name

```bash
sed -i 's/server_name _;/server_name medai.你的域名.com;/' /etc/nginx/sites-available/medai
nginx -t && systemctl reload nginx
```

### 3. 一键签证书

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d medai.你的域名.com
```

certbot 会自动改写 Nginx 配置并开启自动续期。

## 四、上线后必须做的 5 件事

1. **改默认密码**：登录后右上角头像 → 修改密码；`admin/quality/doctor` 三个账号全改。
2. **填 DeepSeek Key**（可选）：
   ```bash
   nano /opt/medai/server/.env      # 填 DEEPSEEK_API_KEY=sk-xxx
   systemctl restart medai
   ```
3. **删演示数据 / 换成真实账号**：
   ```bash
   mysql -uroot -p medai -e "TRUNCATE TABLE ai_messages; TRUNCATE TABLE audit_logs;"
   ```
   或者在「用户管理」里禁用演示账号、新建院内账号。
4. **数据库定时备份**：
   ```bash
   cat > /etc/cron.daily/medai-backup <<'EOF'
#!/bin/bash
mkdir -p /var/backups/medai
mysqldump -uroot medai | gzip > /var/backups/medai/medai-$(date +%F).sql.gz
find /var/backups/medai -name '*.sql.gz' -mtime +14 -delete
EOF
   chmod +x /etc/cron.daily/medai-backup
   ```
5. **关掉 root 密码登录**（可选但强烈建议）：
   ```bash
   sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
   systemctl restart ssh
   ```

## 五、日常运维命令

| 操作 | 命令 |
| --- | --- |
| 看服务状态 | `systemctl status medai` |
| 看实时日志 | `journalctl -u medai -f` |
| 重启服务 | `systemctl restart medai` |
| 更新代码 | 本地重新打包上传 → `cd /opt/medai/web && npm run build:only && systemctl restart medai` |
| 进数据库 | `mysql -um edai -p medai` |
| Nginx 重载 | `nginx -t && systemctl reload nginx` |

## 六、常见问题

**Q：访问 502 Bad Gateway**
`systemctl status medai` 看服务是否挂了；`journalctl -u medai -n 50` 看报错，多半是 `.env` 数据库密码不对或 MySQL 没启动。

**Q：页面能开但接口全 401**
JWT 密钥在部署后被改过，或者浏览器残留旧 token。清 localStorage 重新登录。

**Q：npm install 很慢/超时**
换国内源：
```bash
npm config set registry https://registry.npmmirror.com
```

**Q：内存不足被 OOM**
2G 机器构建前端时容易吃满，加 swap：
```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

**Q：想换端口 8801 → 其他**
改 `/opt/medai/server/.env` 的 `PORT`，同时改 `/etc/nginx/sites-available/medai` 里的 `proxy_pass`，然后两个都 reload。
